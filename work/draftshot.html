DraftShot

Has known limits

A real-time multiplayer game engine. Clients send keyboard-state deltas, the server runs a fixed-step loop designed at 60 ticks/sec, and the authoritative state is the truth.

What it is

A multiplayer game where every client must see the same game, and no client can be trusted to report where it is.

How it works

  • Clients send keyboard-state deltas, not positions.
  • The server runs a fixed-step loop, server-authoritative.
  • A shared physics module runs in the browser and on the server.
  • Collision uses AABB plus Ghost Box.
  • First to 5 wins the round.

How the parts fit together

Client — keyboard-state deltas↓ Server — fixed-step loop↓ Shared physics module↓ Authoritative state back to clients

Stack

Node.js Express Raw WebSockets Spring Boot JavaScript

Honest limits

  • The Java login accepts ANY username with NO password check and issues a JWT.
  • JwtFilter is an empty, unused file.
  • The leaderboard returns a hard-coded list.
  • Players are an in-memory list.
  • Auth hardening is the next task, not a done feature.
