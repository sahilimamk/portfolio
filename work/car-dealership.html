04

Car Dealership

Live demo

A full-stack car dealership application: a React front end, a typed Express API, and a test suite that passes 28 out of 28.

How it works

  • React 19 with Router v7, Tailwind v4, Vite and Axios on the front end.
  • Express 4 with TypeScript 5 on the back end.
  • An in-memory store by default, MongoDB optional.
  • Zod validation, JWT and bcryptjs.
  • Vitest and Supertest: 28 out of 28 tests passing.

How the parts fit together

React 19 front end↓ Express 4 + TypeScript 5 API↓ In-memory store / MongoDB optional↓ Vitest + Supertest — 28/28

Stack

React 19 Router v7 Tailwind v4 Vite Axios Express 4 TypeScript 5 Zod JWT bcryptjs Vitest Supertest MongoDB

Honest limits

  • Server round-trips take about 45–60 seconds on free Render (cold starts).
  • Prices and stock re-seed randomly per load.
